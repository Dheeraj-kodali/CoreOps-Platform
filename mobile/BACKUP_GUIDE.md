# 💾 Database Backup & Restore Guide — Temple Visitor App

---

## 📤 Exporting Database Backup
1. Open Settings ⚙️ (Enter Admin PIN).
2. Tap **Backup & Database Management**.
3. Tap **Export Database Backup (.db)**.
4. Save or share the generated `Temple_Backup_YYYY_MM_DD.db` file to Google Drive, email, or USB storage.

---

## 📥 Restoring Database
1. Open Settings ⚙️ $\rightarrow$ **Backup & Database Management**.
2. Tap **Import Database Snapshot**.
3. Select `.db` backup file from device storage.
4. Review warning pop-up: *"Importing a database will replace the current local data."*
5. Tap **CONFIRM RESTORE**. Data refreshes automatically.
