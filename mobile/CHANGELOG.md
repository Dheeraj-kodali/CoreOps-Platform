# Changelog — Temple Visitor Management System

## [1.0.0] - Version 1.0 Release Candidate 1 (RC1)

### Added
- **Phase 1**: Single-device visitor registration form with required field validation, member counter, and SQLite database storage.
- **Phase 2**: 2-touch Visitor Lifecycle ("VISITOR ENTERED" & "VISITOR LEFT"), real-time header stats, status filter chips, and duration calculator.
- **Phase 3**: Automated Multi-Channel Communication Engine with WhatsApp provider, 16 placeholder tags, and communication history audit trail.
- **Phase 4**: Administrator Configuration Portal with SHA-256 PIN security (`1234`), 5-minute lockout timer, live WhatsApp template preview, tap-to-insert placeholder chips, and test message tool.
- **Phase 5**: Reports Dashboard (`Today`, `Weekly`, `Monthly`, `Custom Range`), multi-field filters, Excel CSV exporter, HTML PDF printable generator, and database backup/restore tool.
- **Final Release Candidate Audit**: Production database migration framework (v2.0), `AppLogger`, indexed query optimization for 50,000+ records, and comprehensive documentation package.
